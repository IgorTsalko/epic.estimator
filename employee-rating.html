Рейтинг эффективности сотрудника

Значения по каждому критерию вводятся вручную за отчётный период. Итоговый рейтинг — единое накопительное число (минимум 0, без верхней границы): если сотрудник по всем критериям ровно «в норме», рейтинг равен 100; всё, что лучше нормы, добавляет баллы, хуже — отнимает свою долю.

Как считается итоговый рейтинг

1. У каждого критерия есть коэффициент — его значимость относительно других. Общий вес всех критериев равен 100 и делится между ними пропорционально коэффициентам: вес = коэффициент / сумма коэффициентов × 100. Поэтому при добавлении нового критерия достаточно задать ему коэффициент — веса остальных пересчитаются автоматически.

2. Значение критерия сравнивается с нормой (ожидаемым значением за период):

  • для критериев «больше — лучше» (↑): балл = вес × значение / норма
  • для критериев «меньше — лучше» (↓): балл = вес × норма / значение

3. Производные критерии считаются автоматически как отношение базовых (например, качество MR = смерженные MR / комментарии к его MR: чем меньше правок потребовалось, тем выше качество) и участвуют в рейтинге со своим весом наравне с базовыми.

4. Итог = сумма баллов по всем критериям. Вклад одного критерия ограничен пятикратным весом (чтобы один аномальный показатель не перекрывал все остальные), сам итог сверху не ограничен. Пустое значение даёт 0 баллов по критерию.
